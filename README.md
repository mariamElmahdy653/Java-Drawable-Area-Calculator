# Java Drawable Area Calculator

## Project Overview

This project is a Java application developed to calculate the total area of different drawable shapes. It demonstrates Object-Oriented Programming (OOP) concepts through a class hierarchy of shapes, with support for graphical user interaction and file handling.

## Technologies Used

- Java
- NetBeans IDE
- Object-Oriented Programming (OOP)
- Graphical User Interface (GUI)
- File Handling

## OOP Concepts

- **Interfaces:** Defines the `Drawable` interface for drawable objects.
- **Inheritance:** Organizes shapes through a class hierarchy.
- **Abstraction:** Uses abstract shape classes to represent shared properties and behaviors.
- **Polymorphism:** Allows different drawable shapes to be handled through a common type.

## Supported Shapes

- **Circle:** Represents a circle with a specified radius.
- **Cube:** Represents a three-dimensional shape with a specified side length.

## Key Features

- Calculate the areas of supported shapes.
- Calculate the sum of the areas of multiple drawable objects.
- Create objects using command-line arguments.
- Display graphical representations of shapes through a GUI.
- Support file input and output.

## Project Structure

The repository contains the Java source code and NetBeans project files required to explore the application.

## How to Run

1. Download or clone this repository.
2. Open NetBeans IDE.
3. Open the project in NetBeans.
4. Build and run the project.

- Apply OOP concepts in a practical Java application.
